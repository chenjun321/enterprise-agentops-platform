# 教育行业销售话术手册

教育行业客户通常关注招生线索、课程顾问跟进效率、活动转化率、数据安全和跨校区协作。

推荐结构：

1. 先确认招生或续费目标。
2. 再定位线索分散、跟进慢、活动 ROI 难衡量的问题。
3. 说明系统如何统一客户、活动、客服和订单数据。
4. 推进小范围试点，避免一开始承诺大规模替换。

异议处理：

- 如果客户担心数据安全，强调只读权限、字段脱敏和审计日志。
- 如果客户担心实施成本，建议从一个校区或一个活动开始。

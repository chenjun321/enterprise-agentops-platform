# C 端用户常见问题

用户身份优先使用 customer_user_id。若用户无法提供账号 ID，可补充钱包地址、社交账号、订单号、活动名称、页面 URL 或截图中的错误提示。

登录或钱包连接失败时，先建议用户刷新页面、确认钱包插件已解锁、切换到正确网络、重新签名。若仍失败，需要收集发生时间、钱包地址、浏览器、设备型号和截图。

任务、活动或奖励问题需要先确认活动名称、任务名称、用户账号、提交时间和页面 URL。奖励到账可能存在处理延迟，用户可先刷新页面并稍后查看。

支付或订单问题需要用户提供订单号、支付时间和交易流水截图。若支付成功但状态未同步，系统会继续核对，客服可通过工单跟进。

当用户反馈功能异常、无法完成任务、页面报错或结果不符合预期时，应创建反馈工单，并要求用户保留页面、时间、截图或录屏。
